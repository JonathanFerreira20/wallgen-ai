# WallGen AI 🚀

WallGen AI is a futuristic wallpaper generator built with HTML, CSS, and JavaScript.

The project allows users to generate dynamic wallpapers with animated visual effects, futuristic themes, neon UI, and responsive mobile design.

## ✨ Features

* Dynamic wallpapers using Pexels API
* Cyberpunk inspired interface
* Animated intro screen
* Neon effects and particles
* 3D parallax interaction
* Download wallpaper feature
* Responsive mobile layout
* PWA support (installable app)

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Pexels API

## 📱 Responsive Design

The application is fully responsive and optimized for both desktop and mobile devices.
